# TRPG 规则数据来源登记

日期：2026-10-21　范围：`allin_engine/trpg/`（约 2,800 行）
性质：**工程侧的来源登记与整改记录**，不是法律意见；对外分发前建议法务复核。

## 一、为什么要做这件事

`data.py` 原有注释写的是"融合 D&D 三宝书（PHB / DMG / MM）与 GURPS Basic Set 的机制"。
这句话有两处问题：

1. **PHB / DMG / MM 是专有出版物**，不在任何开放许可下；说"融合"会让人以为复制了原文。
   真正可用的开放版本是 **SRD 5.1**（Wizards of the Coast 于 2023 年以 **CC-BY-4.0** 发布）。
2. **GURPS Basic Set 也无开放许可**。本项目实际用的是"点数制 / 难度分级 / 战斗机动"这类
   **通用规则概念**，属于思想而非表达，但表述成"融合 Basic Set"同样会造成误解。

代码是 MIT，数据来源必须在仓库里说清楚——否则下游（尤其商用）无法判断能不能用。

## 二、三分法

| 类别 | 含义 | 处理方式 |
|---|---|---|
| **A · 可溯源** | 数值/名称来自 **SRD 5.1**（CC-BY-4.0） | 保留，但必须署名（根 `NOTICE` 已加官方署名段） |
| **B · 通用机制 / 自研** | 点数阶梯、难度成本、公式、数据结构等 | 无需许可；在 `docs/借鉴记账.md` 记为"公共知识/自研" |
| **C · 待复核** | 中文描述短句、术语译名、未来新增的文本 | 不逐条比对就不宣称"原创"；新增时必须登记 |

## 三、逐表登记

| 数据表 | 类别 | 说明 |
|---|---|---|
| `ATTRIBUTES` | B | 六属性是通用设计（STR/DEX/CON/INT/WIS/CHA），非某本书的表达 |
| `ATTR_COST_BRACKETS` | B | 自研递增标价（低段便宜、高段陡升），无外部对照表 |
| `EQUIPMENT_LIBRARY` | **A** | 武器**伤害骰**与护甲 **AC / 敏调上限**与 SRD 5.1 一致；**重量与 CP 为本仓折算值**，不是 SRD 原值（如长剑 SRD 3 lb，此处 4；全身板甲 SRD 65 lb，此处 33） |
| `ARMOR_PROFICIENCY` | B | "中甲需闪避防御"是本仓的熟练度映射，非 SRD 规则 |
| `WEAPON_DICE` | **A** | 与 `EQUIPMENT_LIBRARY` 同源，SRD 5.1 伤害骰 |
| `FINESSE_WEAPONS` | **A** | SRD 5.1 的 finesse 武器集合（译名） |
| `SKILL_LIBRARY` | **A**（名称） / B（结构） | 18 项技能名与 SRD 一致（中文译名）；难度分级 E/A/H/VH、成本、分类为本仓自研 |
| `DIFFICULTY_COST` / `SKILL_CATEGORIES` | B | 自研 |
| `TECHNIQUES` | B | 条目为通用战技动作（佯攻、快速打击、全力攻击等）的中文命名与自研 CP/前置；**未复制任何规则书描述文本** |
| `TALENT_BONUS_GROUPS` | B | 自研 |
| `ADVANTAGES_LIBRARY` / `DISADVANTAGES_LIBRARY` | B | "优点/缺点返点"是通用点数制概念；条目与点值为本仓自研 |
| `SPELL_SLOT_CAPS` / `SPELL_SLOT_COST` / `SPELL_RING_PREREQ` / `SPELL_RINGS` | B | 环形法术位的上限与成本为自研（与 D&D 的"法术位"不是同一套数值） |
| `FEATS_LIBRARY` | **A**（名称/前置） / B（效果） | 专长名取 SRD 5.1 并译为中文（如"强壮""警觉"）；效果通过事件钩子自研挂钩 |
| `RACE_TEMPLATES` / `BACKGROUNDS` | **A**（名称） / B（数值） | 种族/背景名取 SRD 5.1；属性加成与授予技能为本仓简化值 |
| `ELEMENTS` | B | 四元素，通用 |
| `data.py` 中所有**中文描述短句** | **C** | 均为功能性短语（如"1d4 穿刺，灵巧/可投掷"），未见成段文学性描述；**未逐条与任何中文译本比对** |

抽查结论（2026-10-21）：`EQUIPMENT_LIBRARY` 的伤害骰与 AC 与 SRD 5.1 一致；
重量全部为本仓折算（普遍约为 SRD 磅值的一半），不构成对原表的复制。

## 五、仍未解决 / 需要人工复核

1. **术语译名可能与市面中文译本重合**（"敏捷""强韧""熟练"等属通用译法）。
   本项目不主张译名原创，但也没有逐条比对；若要求更强隔离，应统一改用自造词。
2. **描述短句未逐条比对**（C 类）。当前判断依据是"长度短、只含机制信息、无文学修辞"，
   属于工程判断，不是法律结论。
3. **未来新增内容**：任何来自 SRD 之外的法术/怪物/背景**描述文本**，必须先登记来源；
   只允许"数值 + 自写功能性说明"，不允许整段翻译。
4. **许可并存**：代码 MIT、数据 CC-BY-4.0。分发时应同时提供 `LICENSE` 与 `NOTICE`；
   若下游只取代码、不取 `trpg/` 数据，可仅遵循 MIT。
